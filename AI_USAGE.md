# AI Usage and Citation Report

**Course Module:** OPSC6321 - Mobile Development
**AI Tool Used:** Android Studio Gemini

---

## 1. Summary of AI Use
AI tools were used primarily for debugging assistance and minor code generation tasks during the development of this application.

## 2. Key Use Cases
*   **Debugging Errors**: AI assisted in resolving minor Gradle configuration issues and fixing Kotlin syntax errors during the development of the UI.
*   **Minor Boilerplate**: Used to generate standard boilerplate code for some data classes and basic UI components to save time on repetitive tasks.
*   **Resource Management**: Assisted in identifying and correcting minor resource naming conflicts and file extension issues.

## 3. Conclusion
All AI-generated suggestions were manually reviewed, edited, and tested by the team to ensure they fit the project's specific requirements. AI served as a simple support tool for error checking and minor task automation.
