# AI Usage and Citation Report

**Course Module:** OPSC6321 - Mobile Development
**AI Tools Used:** Android Studio Gemini; Copilot SDK in VS Code

---

## 1. Summary of AI Use
AI tools supported debugging and implementation during development. The team reviewed generated suggestions and remains responsible for validating the application and its assessment evidence.

## 2. Key Use Cases
*   **Debugging and configuration**: Gemini was used for earlier Gradle/Kotlin troubleshooting. Copilot helped diagnose the missing Google Web OAuth client configuration and wire a Gradle-property fallback for Google sign-in.
*   **Feature implementation**: Copilot assisted with the profile-photo flow using private Supabase Storage via the Firebase-authenticated API and Cloud Firestore, plus FCM topic subscriptions and Android notification permission handling.
*   **Documentation**: AI-assisted edits were made to the README and Part 3 release notes.

## 3. Conclusion
The team reviewed and edited the suggestions. The Android Kotlin compilation and unit-test task completed successfully in the development environment. Supabase/API configuration, Firestore rules, device sign-in, and physical-device notification delivery still require manual verification before submission.
